## 🧰 Crea Tu Propia Guía — App Guide Builder

> **¿Quieres una guía hecha solo para tu proveedor y tus canales?** La app gratis **EPGTalk Guide Builder** para **Windows** y **Linux** la crea en tu propia computadora.

- 📡 Escribe tu código postal, elige tu proveedor (cable, satélite o antena) y marca tus canales — con logos
- 📲 Presiona **Crear** — tu TV box carga la guía directo desde tu computadora (sigue compartiendo en segundo plano)
- 📺 Guía de TV incluida con búsqueda, y un corrector que une tu lista `.m3u` con la guía
- 🕓 Una guía nueva cada día, actualizaciones con un clic, English y Español, apariencia clara y oscura
- 🖥️ **Versión NAS / Docker (2.1):** úsala 24/7 en tu NAS o servidor de casa con Docker (Synology, QNAP, Unraid…) y manéjala desde cualquier navegador — [cómo instalarla](https://epgtalk.com/builder/#nas)
- 🏆 **Nuevo en la 1.4:** agrega las guías gratis de EPGTalk y quédate solo con los canales que quieres (tus equipos de Deportes, unos canales de Pluto de TV gratis) para una guía más chica que carga rápido en un Firestick

**➡️ [Descarga el Guide Builder](https://epgtalk.com/builder/)** — gratis, sin cuenta. ¿Ya usas mc2xml? Importa tus archivos `.dat` / `.chl` / `.ren`, o usa el mc2xml de reemplazo directo para scripts y servidores.

## ❓ Preguntas Frecuentes

<details>
<summary><strong>📭 Mi guía no muestra datos — ¿qué hago?</strong></summary>

Asegúrate de usar la URL **raw** de GitHub que comienza con `raw.githubusercontent.com` — NO la URL normal de la página de GitHub. Después de agregar la fuente, cierra completamente y reinicia tu app. Dale unos minutos para descargar — la guía Combinada pesa más de 40 MB.

</details>

<details>
<summary><strong>🔁 Sincronizo EPGTalk con git y <code>git pull</code> falla</strong></summary>

Para que el repositorio sea pequeño y rápido, solo guarda las guías **más recientes** — el historial se reemplaza en cada actualización, así que `git pull` muestra *unrelated histories* o *divergent branches*. Actualiza tu copia con esto:

```bash
git fetch --depth 1 origin master && git reset --hard origin/master
```

O mejor, no uses git: configura tu app con las URLs de las guías de arriba — es más fácil y siempre está al día.

</details>

<details>
<summary><strong>📺 Falta un canal o muestra información incorrecta</strong></summary>

Espera **24 horas** — la guía se actualiza cada noche y la mayoría de los problemas se resuelven solos. Si el canal sigue fallando después de 2 días, publica en el hilo de IPTVTalk que está abajo o escribe a **support@epgtalk.com**.

</details>

<details>
<summary><strong>🔄 ¿Con qué frecuencia se actualiza la guía?</strong></summary>

Cada noche, completamente automatizado. El proceso corre de madrugada y para las 9:30 PM (hora del centro de EE.UU.) los datos frescos ya están en GitHub. Configúralo una vez, olvídalo para siempre.

</details>

<details>
<summary><strong>📦 ¿Debo usar .xml o .xml.gz?</strong></summary>

Siempre `.xml.gz` — son exactamente los mismos datos pero comprimidos, hasta **10 veces más pequeños**. Se descargan más rápido y pesan menos en tu dispositivo. Solo usa `.xml` si tu app específicamente no soporta gzip.

</details>

<details>
<summary><strong>🌍 ¿Puedo usarlo fuera de EE.UU. / UK / México?</strong></summary>

100% sí — está alojado en el CDN global de GitHub, accesible desde cualquier parte del mundo.

</details>

<details>
<summary><strong>📡 ¿Cuál es la diferencia entre Guía EE.UU. y EE.UU. Local?</strong></summary>

**Guía EE.UU.** = canales nacionales de cable/satélite (ESPN, CNN, TNT, etc.)
**EE.UU. Local** = afiliadas locales de transmisión (ABC, NBC, CBS, FOX, PBS) en **140+ mercados individuales**. Son cosas diferentes — usa ambas para cobertura máxima.

</details>

<details>
<summary><strong>🔓 ¿Es legal?</strong></summary>

EPGTalk proporciona datos de programación de TV — piénsalo como una guía digital de canales. Es **solo para uso legal de IPTV**. Asegúrate siempre de que tu servicio IPTV sea legítimo y tenga las licencias correspondientes.

</details>

<details>
<summary><strong>🤝 ¿Puedo solicitar un canal o contribuir?</strong></summary>

¡Claro que sí! Publica en el hilo del foro IPTVTalk que está abajo. Solicitudes de canales, sugerencias de proveedores, reportes de errores — todo es bienvenido. Esto fue creado por y para la comunidad.

</details>
